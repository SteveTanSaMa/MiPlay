# MiPlay 产品愿景

## 产品定位

MiPlay 是一款面向 macOS 用户的米哈游游戏启动器，专注于解决 Wine 兼容环境下的游戏启动与运行问题。它将隐藏 Wine 技术复杂性，让用户像打开普通 macOS 应用一样启动米哈游游戏。

## 目标用户

**核心用户群：**
- macOS 游戏玩家，同时运行多款米哈游游戏
- 需要统一管理游戏启动，不愿切换多个独立启动器
- Wine 兼容性敏感用户，需要内置解决方案

**技术接受度：**
- 具备基础技术操作能力（下载解压、应用安装）
- 可能对 Wine/转译/容器概念感到困惑
- 愿意通过社区文档或设置解决配置问题

## 核心价值主张

1. **单一统一入口**
   - 一个应用启动所有米哈游游戏
   - 游戏状态（安装/就绪/运行/更新）一目了然

2. **技术零感知**
   - Wine 环境自动配置，无需理解技术细节
   - 所有兼容方案由产品内置提供

3. **版本主题沉浸**
   - 每款游戏显示当前版本官方背景素材
   - 与游戏版本主题保持一致

4. **高效维护**
   - 自研 sophon 增量更新节省流量和时间
   - 游戏文件完整性自动校验
   - 多版本共存管理

## 成功标准

| 维度 | 衡量方式 | 目标值 |
|------|----------|--------|
| 启动成功 | 成功启动 / 尝试启动 | ≥ 95% |
| 更新效率 | 增量更新 vs 完整下载 | 节省 ≥ 80% |
| 用户路径 | 首次启动游戏平均步骤数 | ≤ 4 步 |
| 游戏覆盖 | 支持的米哈游游戏 | 全部 5 款 |
| 无感使用 | 需用户干预的启动比例 | ≤ 5% |

## 收敛声明

> MiPlay **专注**于米哈游系列游戏在 macOS 上的启动与运行。**不**解决以下需求：
> - 账号管理或登录凭据处理
> - 游戏 Mod 管理或画质设置
> - 社区交流或社交功能
> - 非米哈游游戏支持
> - 多用户切换
> - 反作弊绕过
>
> 这些不是产品目标，我们不消耗开发资源。
