# Apple Developer Documentation — Liquid Glass

This is a collection of Apple Developer documentation about **Liquid Glass**, the dynamic material introduced across Apple platforms that combines the optical properties of glass with a sense of fluidity.

## Collection Details

- **Date collected:** 2026-07-13
- **Source:** Apple Developer Documentation (developer.apple.com) in Markdown format
