# MiPlay 参考项目

本工程继续专注 MiPlay 的开发、运行时集成与用户体验。DXMT 与 LSFG 的底层研发在各自独立工程中进行；此处仅保留个人 fork 的参考克隆，不将其源码纳入 MiPlay 的 Git 跟踪。

| 本地目录 | 仓库 | 2026-10-09 克隆版本 |
| --- | --- | --- |
| `dxmt/` | [SteveTanSaMa/DXMT](https://github.com/SteveTanSaMa/DXMT) | `e94c312f5c054263acf261cfa109edf13e757587` |
| `lsfg/` | [SteveTanSaMa/LSFG](https://github.com/SteveTanSaMa/LSFG) | `07647495e85fea78ac30a8499867c51306fee150` |

从 MiPlay 项目根目录通过本机 SSH 克隆：

```sh
git clone git@github.com:SteveTanSaMa/DXMT.git References/dxmt
git clone git@github.com:SteveTanSaMa/LSFG.git References/lsfg
```

旧 `lsfg-metal/` 与 `Lossless Scaling/` 已移除。历史调研文档中的旧仓库地址和路径保留为当时的研究依据；后续研究使用上述 fork。
